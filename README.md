# Kali Linux Lab Setup

## Overview

This project documents the installation and initial setup of Kali Linux in a virtual environment using Oracle VirtualBox.

The goal of this lab is to create a dedicated environment for learning Linux and cybersecurity fundamentals.

---

## Installation

1. Download the Kali Linux ISO from the official Kali Linux website.
2. Install Oracle VirtualBox on the host machine.
3. Create a new virtual machine and allocate memory and storage.
4. Attach the Kali Linux ISO to the virtual machine.
5. Boot the virtual machine and complete the Kali Linux installation.
6. Reboot the machine and verify that Kali Linux starts correctly.
