The purpose of this lab is to create a simple environment for learning Linux and basic cybersecurity concepts.

Installation
Download the Kali Linux ISO from the official Kali Linux website.
Install Oracle VirtualBox.
Create a new virtual machine.
Attach the Kali Linux ISO file.
Start the virtual machine and follow the installation process.
Reboot the virtual machine after installation is complete.
Verify that Kali Linux boots successfully.
